# Cookie Cats A/B Test Analysis

Анализ A/B-теста мобильной игры Cookie Cats (Tactile Entertainment):  
влияние переноса первого гейта с 30-го на 40-й уровень на удержание игроков.

## О проекте

Cookie Cats — популярная puzzle-игра в жанре «connect three».  
По мере прохождения уровней игрок сталкивается с **гейтами** — точками, где его останавливают и предлагают подождать или сделать внутриигровую покупку.

Изначально первый гейт стоял на **30-м уровне**.  
Команда провела эксперимент, в котором перенесла его на **40-й уровень**, и хотела понять, как это повлияет на удержание.

- **Control:** `gate_30`
- **Treatment:** `gate_40`

В проекте я:
1. Провёл полный анализ результатов реального эксперимента
2. Отдельно описал, как бы спроектировал этот тест сам (метрики, MDE, sample size, сегменты, decision framework)

## Технологии

- Python
- pandas, numpy
- scipy, statsmodels

## Данные

Источник kaggle: https://www.kaggle.com/datasets/mursideyarkin/mobile-games-ab-testing-cookie-cats


- 90 189 игроков, установивших игру во время эксперимента
- Поля:
  - `userid`
  - `version` (`gate_30` / `gate_40`)
  - `sum_gamerounds` — количество раундов за первые 14 дней
  - `retention_1` — вернулся ли игрок на 1-й день
  - `retention_7` — вернулся ли на 7-й день

## Метрики

| Тип        | Метрика              | Роль                          |
|------------|----------------------|-------------------------------|
| Primary    | `retention_7`        | Главный критерий решения      |
| Secondary  | `retention_1`        | Ранний сигнал удержания       |
| Secondary  | `sum_gamerounds`     | Вовлечённость                 |
| Guardrail  | `retention_1`        | Не должна значимо упасть      |
| Guardrail  | median gamerounds    | Не должна значимо упасть      |

## Основные результаты

| Метрика          | Разница (40 − 30) | p-value | 95% CI              | Вывод                    |
|------------------|-------------------|---------|---------------------|--------------------------|
| **retention_7**  | −0.82 п.п.        | 0.0016  | [−1.33%, −0.31%]    | Стат. значимо хуже       |
| retention_1      | −0.59 п.п.        | 0.0744  | [−1.24%, +0.06%]    | Значимой разницы нет     |
| sum_gamerounds   | −1 (медиана)      | 0.0502  | —                   | Значимой разницы нет     |

Дополнительно:
- Обнаружен лёгкий Sample Ratio Mismatch (p ≈ 0.009)
- В `gate_30` есть один экстремальный выброс по `sum_gamerounds` (49 854). Основные выводы по retention от него не зависят; по вовлечённости опираемся на медиану и Mann-Whitney

## Рекомендация

**Не переносить гейт на 40-й уровень.**

Перенос статистически значимо снижает 7-дневное удержание.  
Краткосрочное удержание и количество раундов при этом не выигрывают.
